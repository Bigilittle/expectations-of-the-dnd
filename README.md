## Описание проекта

Проект представляет собой веб-приложение для расчёта математических ожиданий урона в Dungeons & Dragons.

Пользователь вводит:
- список атак (тип, модификаторы, урон и его тип),
- параметры персонажа, по которому совершаются атаки (КД, спасброски и т.д.).

После ввода данных система рассчитывает:
- математическое ожидание урона,
- вероятность получения определённого количества урона,
- дополнительные параметры, связанные с успешностью/неуспешностью атак.

Цель проекта — упростить анализ боевых взаимодействий в DnD и сделать подготовку к бою (или разбор логов) более наглядной и точной.


## Статус проекта

На данный момент запускается только фронтенд.  
Фронтенд не завершён, находится в процессе активной разработки.  
Бэкенд в разработке

## Как запустить

> Убедитесь, что у вас установлен [Docker Desktop](https://www.docker.com/products/docker-desktop)

1. Перейдите в корень проекта:

```bash
cd path/***
```

2. Запустите проект:
```bash
docker compose up --build
```

3. Перейдите в браузере на:
[http://localhost:3000](http://localhost:3000) (на данный момент не выведено на сервер)
